# Ryesoma — Open Food Facts derivative database

This repo hosts the Open Food Facts–derived subset of the food database used by
[Ryesoma](https://github.com/weft-witch-labs/ryesoma), by Weft Witch Labs. It's published here,
separately from the app's source code, to satisfy the share-alike terms of the
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/), under
which Open Food Facts data is licensed.

See the [Releases](../../releases) tab for the downloadable database file, and the app
repo's `ATTRIBUTION.md` for full attribution and license details, including exactly what
adaptations were made to the source Open Food Facts data.
